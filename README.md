# Spec-Driven Development — SELF 2026

Slidev presentation for SouthEast LinuxFest 2026.

## Viewing

Install Slidev either from npm or your preferred package manager

```bash
npm i -g @slidev/cli
```

Then run the `slidev` command and it will provide links to open the slides in your browser.
```bash
cd SELF2026
slidev
```

Then open http://localhost:3030 in your browser.
